## 4. 화면 구조 및 네비게이션

### 4.1 PC 웹 네비게이션 (사이드바)

```
┌─────────────────────────────────────────┐
│ [사이드바]        │ [메인 콘텐츠 영역]    │
│                   │                      │
│ 🔍 검색           │                      │
│ ─────────────     │                      │
│ 📅 캘린더         │                      │
│ ✅ Todo 목록  ←기본│                      │
│ 🎯 우선순위 뷰    │                      │
│ 🏷️ 카테고리      │                      │
│ ─────────────     │                      │
│ ⚙️ 설정           │                      │
└─────────────────────────────────────────┘
```

- 기본 진입 화면: **Todo 목록**
- 검색: 사이드바 상단 고정 아이콘 탭 → 검색창 펼쳐짐

### 4.2 모바일 네비게이션 (하단 탭바)

```
┌─────────────────────────┐
│      메인 화면 영역      │
├──────┬──────┬─────┬─────┤
│ 캘린 │ Todo │우선 │ 설정 │
│ 더   │ 목록 │순위 │     │
└──────┴──────┴─────┴─────┘
```

- 기본 진입 화면: **Todo 목록**
- 검색: 각 화면 상단 돋보기 아이콘 탭 → 검색창 펼쳐짐
- 카테고리 관리: 설정 화면 내 별도 페이지

### 4.3 상세 보기 및 편집 방식

| 항목 | 내용 |
|------|------|
| 상세 보기 | 모달 (PC: 팝업 / 모바일: 시트 형태로 아래에서 올라옴) |
| 편집 방식 | 별도 편집 모드 전환 — 모달 안에서 편집 버튼 클릭 시 입력 가능 상태로 전환 |

### 4.4 화면별 주요 기능

#### 캘린더
- 월간 / 주간 / 일간 뷰 전환 탭
- **월간 뷰**: 날짜 셀 안에 일정 제목 작게 표시 (구글 캘린더 스타일). 많으면 "+N개"
- **주간 뷰**: 1시간 단위 시간 블록 (설정에서 변경 가능). 카테고리 색상 적용
- **일간 뷰**: 1시간 단위 시간 블록 + 당일 Todo 섹션 통합
- PC에서 드래그 앤 드롭으로 일정 날짜/시간 변경

#### Todo 목록
- 필터 탭: **미완료** (기본) / **완료** / **전체**
- 정렬 탭: **시간순** / **점수순**
- **시간순 정렬 섹션 구조**:
  - 기한 있는 Todo → 마감 기한 오름차순
  - `── 기한 없음 ──` 구분선 이후 → 기한 없는 Todo
- **완료 처리 UX**:
  - 체크 즉시 취소선 + 맨 아래로 이동
  - "미완료" 탭에서는 즉시 사라짐
  - "완료" / "전체" 탭에서는 취소선으로 하단에 표시
  - 완료 후 설정 기간(기본 30일) 경과 시 자동 영구 삭제
- 스와이프 액션 (모바일): 오른쪽 → 완료, 왼쪽 → 삭제

#### 카테고리 (PC 전용 사이드바 항목)
- 대카테고리 목록 및 소카테고리 트리 표시
- 대카테고리 추가·수정·삭제
- 소카테고리 추가·수정·삭제
- 각 카테고리별 이름 / 색상 / 기본 중요도 설정

#### 우선순위 뷰
- 상단 탭: **매트릭스** / **점수 목록** 전환
- 필터: 전체 / 일정만 / Todo만 / 카테고리별

#### 설정
- 테마 (라이트 / 다크 / 시스템)
- 기본 알림 시각 (10분/30분/1시간/하루 전)
- 스누즈 시간 (기본 10분, 변경 가능)
- 완료된 Todo 자동 삭제 기간 (기본 30일)
- 지난 일정 자동 삭제 기간 (기본 180일)
- 주간·일간 뷰 시간 블록 단위 (기본 1시간, 변경 가능)
- 카테고리 관리 (모바일 전용 — PC는 사이드바에서 관리)

## 5. 일정 vs Todo 비교

> 두 유형은 **동일한 폼**으로 등록. `is_todo` 토글 하나로 구분. DB 필드도 공유.

| 항목 | 일정 (Schedule) | Todo |
|------|----------------|------|
| 핵심 개념 | 특정 시간에 일어나는 일 | 언젠가 완료해야 할 작업 |
| 시작 시각 | **필수** | 선택 (레이블: "마감 기한") |
| 종료 시각 | **필수** (미입력 시 당일 23:59 자동) | 없음 |
| 마감 정밀도 | 해당 없음 | 연/월/일/시분 선택 가능 |
| 기한 초과 동작 | 해당 없음 | 만료(expire) / 유지(keep) |
| 만료 표시 | 해당 없음 | 빨간색 강조 + 만료 뱃지. 목록 유지 |
| 완료 체크 | 없음 (시간 지나면 자연 종료) | 있음 |
| 자동 삭제 | 종료 후 설정 기간(기본 180일) | 완료 후 설정 기간(기본 30일) |
| 알림 | 시작 시각 기준. 종일이면 "하루 전"만 가능 | 마감 기한 기준. 기한 없으면 알림 불가 |
| 반복 설정 | 있음 (매 회차마다 알림 자동 발송) | 있음 (매 회차마다 알림 자동 발송) |
| 중요도 | 1.0~10.0 (카테고리 기본값 자동 적용) | 1.0~10.0 (카테고리 기본값 자동 적용) |
| 카테고리 | 대>소 2단계 | 대>소 2단계 |
| 장소·메모 | 있음 | 있음 |
| 캘린더 표시 | 시간 블록 | 일간 뷰 하단 Todo 섹션 |
| 매트릭스 X축 | **start_at** 기준 긴급도 | **start_at**(마감 기한) 기준 긴급도 |

## 6. 주요 기능 명세

### 6.1 할 일 (Todo) 관리

| 기능 | 상세 |
|------|------|
| 기본 CRUD | 추가 / 수정 / 삭제 / 완료 체크 |
| 중요도 | 1.0~10.0. 카테고리 선택 시 해당 카테고리 기본 중요도로 자동 채움 |
| 마감 기한 | 선택사항. 연/월/일/시분 정밀도 선택 가능 |
| 마감 저장 방식 | precision=year → 해당 연도 12/31 23:59 저장. precision=month → 해당 월 마지막 날 23:59 저장 |
| 기한 초과 동작 | 만료(expire): 빨간색 강조 + 만료 뱃지 표시, 목록 유지 / 유지(keep): 표시 변화 없음 |
| 완료 UX | 체크 즉시 취소선 + 맨 아래 이동. 미완료 탭에서 즉시 사라짐 |
| 자동 삭제 | 완료 후 설정 기간(기본 30일) 경과 시 영구 삭제 |
| 알림 | 마감 기한 기준. 기한 없으면 알림 설정 UI 비활성화 |
| 목록 구조 | 시간순: 기한 있는 항목 → 기한 없는 항목 (별도 섹션) |

### 6.7 카테고리

> **대카테고리 > 소카테고리** 2단계 구조.
> 카테고리 선택 시 해당 카테고리의 **기본 중요도**가 폼에 자동 적용됨.

기본 제공 대카테고리:

| 카테고리 | 색상 | 기본 중요도 |
|---------|------|------------|
| 업무 | 🔵 파랑 | 7.0 |
| 개인 | 🟣 보라 | 5.0 |
| 건강 | 🟢 초록 | 6.0 |
| 가족 | 🟠 주황 | 6.0 |
| 기타 | ⚫ 회색 | 5.0 |

- 대카테고리·소카테고리 모두 **독립 색상** 설정 가능
- 대카테고리·소카테고리 모두 **기본 중요도** 설정 가능
- 소카테고리 선택 시 소카테고리의 기본 중요도 우선 적용 (없으면 대카테고리 값)
- 대카테고리 삭제 시 소속 일정·Todo는 '기타'로 자동 이동
- PC: 사이드바 카테고리 항목에서 관리 / 모바일: 설정 화면에서 관리

### 6.8 중요도 기반 우선순위 뷰

#### 아이젠하워 매트릭스
- X축: 긴급도 (일정은 start_at, Todo는 마감 기한까지 남은 시간. 오른쪽으로 갈수록 긴급)
- Y축: 중요도 (importance 값, 위로 갈수록 중요)
- 4분면: 긴급+중요 / 비긴급+중요 / 긴급+비중요 / 비긴급+비중요
- 마감 기한 없는 Todo는 X축 맨 왼쪽(비긴급)에 배치
- 각 점 클릭 시 해당 항목 모달로 이동

#### 우선순위 점수 목록
- 점수 공식: `중요도 × 긴급도점수`
- 긴급도점수: 24시간 이내=10, 1주일=7, 1달=5, 기한없음=1
- 점수 내림차순 정렬

| 항상 위에 표시 | 토글 (기본값: false) |
| 시스템 트레이 | 트레이 아이콘 상주, 우클릭 메뉴 |
| 자동 실행 | 맥 로그인 시 자동 시작 |
| 전역 단축키 | `Ctrl+Shift+F` — 위젯 표시/숨김 |

### 6.11 모바일 전용 기능 (Android)

| 기능 | 상세 |
|------|------|
| 홈화면 위젯 (소) | 다음 일정 하나 + 미완료 Todo 개수 |
| 홈화면 위젯 (중) | 오늘 일정 목록 (최대 5개) |
| 홈화면 위젯 (대) | 이번 주 미리보기 |
| 앱 아이콘 배지 | 미완료 Todo 개수 표시 |
| 스와이프 액션 | 오른쪽 → 완료, 왼쪽 → 삭제 |

### 6.12 일정 등록 폼 세부 스펙

> Todo와 일정은 **동일한 폼** 사용. `is_todo` 토글 하나로 구분.

| 구분 | 필드 | 세부 동작 |
|------|------|----------|
| 필수 | 제목 | 최대 100자 |
| 조건부 필수 | 시작 시각 | 일정은 필수. Todo는 선택 (레이블 → "마감 기한") |
| 선택 | Todo/일정 토글 | `is_todo` 전환 |
| 선택 | 종료 시각 | 일정 전용. 미입력 시 당일 23:59 자동 설정 |
| 선택 | 종일 여부 | 켜면 시간 입력 UI 숨김. 알림은 "하루 전"만 활성화 |
| 선택 | 대카테고리 | 기본값: 기타. 선택 시 기본 중요도 자동 적용 |
| 선택 | 소카테고리 | 대카테고리 선택 후 표시. 선택 시 소카테고리 기본 중요도 우선 적용 |
| 선택 | 중요도 | 1.0~10.0 슬라이더 또는 직접 입력. 카테고리 선택 시 자동 채움 |
| 선택 | 마감 정밀도 | 연/월/일/시분 중 선택. Todo일 때만 표시 |
| 선택 | 기한 초과 동작 | 만료(expire) / 유지(keep). Todo일 때만 표시 |
| 선택 | 반복 설정 | 보조 패널 펼치면 표시. 종료 조건은 생성 후에도 변경 가능 |
| 선택 | 알림 설정 | 마감/시작 기준. 종일이면 하루 전만. 기한 없는 Todo는 비활성화 |
| 선택 | 장소 | 최대 100자 |
| 선택 | 메모 | 글자 수 제한 없음 |

## 8. 데이터 모델 (PocketBase Collections)

### schedules
```
id                 : string   (자동 생성)
title              : string   (필수, 최대 100자)
description        : text     (선택, 글자 수 제한 없음)
location           : string   (선택, 최대 100자)
start_at           : datetime (일정 필수. Todo는 선택 — 마감 기한으로 사용)
end_at             : datetime (일정: 미입력 시 당일 23:59 자동 설정)
is_all_day         : bool     (기본값: false)
is_todo            : bool     (기본값: false) ← Todo이면 true
is_completed       : bool     (기본값: false, Todo 전용)
completed_at       : datetime (완료 시각, 자동 기록, Todo 전용)
importance         : float    (1.0~10.0, 10이 가장 중요. 카테고리 기본값 자동 적용)
category_id        : relation → categories (대카테고리)
sub_category_id    : relation → categories (소카테고리, nullable)
deadline_precision : select   [none, year, month, day, datetime] (Todo 전용)
expire_type        : select   [expire, keep] (기한 초과 시 동작. 기본값: keep, Todo 전용)
repeat_type        : select   [none, daily, weekly, monthly, yearly]
repeat_days        : json     (요일 배열, 예: [1,3,5] = 월·수·금)
repeat_end_at      : datetime (반복 종료일, nullable. 생성 후 언제든 변경 가능)
repeat_count       : number   (반복 횟수, nullable)
parent_id          : relation → schedules (반복 원본 참조)
reminder_mins      : json     (알림 시각 배열, 예: [10, 30, 60])
created            : datetime (자동)
updated            : datetime (자동)
```

### categories
```
id                 : string (자동 생성)
parent_id          : relation → categories (null=대카테고리, 값 있음=소카테고리)
name               : string (필수)
color              : string (HEX 색상코드. 대·소 카테고리 모두 독립 설정)
default_importance : float  (1.0~10.0. 폼에서 카테고리 선택 시 자동 적용. 기본값: 5.0)
order              : number (정렬 순서)
```

### notifications
```
id            : string   (자동 생성)
schedule_id   : relation → schedules (해당 일정/Todo)
fire_at       : datetime (알림 발송 예정 시각)
status        : select   [pending, sent, snoozed, dismissed]
snoozed_until : datetime (스누즈 시 재발송 시각, nullable)
created       : datetime (자동)
```

### settings
```
id                    : string
theme                 : select [light, dark, system]
default_reminder      : json   (기본 알림 시각 배열, 예: [10, 30])
snooze_minutes        : number (스누즈 시간(분). 기본값: 10)
todo_delete_days      : number (완료된 Todo 자동 삭제 기간. 기본값: 30)
schedule_delete_days  : number (지난 일정 자동 삭제 기간. 기본값: 180)
calendar_slot_mins    : number (주간·일간 뷰 시간 블록 단위(분). 기본값: 60)
```
