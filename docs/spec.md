## 1. 화면 구조 및 네비게이션

### PC 웹 (사이드바)

```
┌──────────────────────────────────────────┐
│ [사이드바]         │ [메인 콘텐츠 영역]    │
│                    │                      │
│ 🔍 검색            │                      │
│ ────────────────   │                      │
│ 📅 캘린더          │                      │
│ ☑️ 목록    ←기본   │                      │
│ 🎯 우선순위 뷰     │                      │
│ 🏷️ 카테고리       │                      │
│ ────────────────   │                      │
│ ⚙️ 설정            │                      │
└──────────────────────────────────────────┘
```

- 기본 진입 화면: **목록** (Todo / 일정 탭 전환)
- 검색: 사이드바 돋보기 아이콘 → 검색창

### 모바일 (하단 탭바)

```
┌──────┬──────┬──────┬──────┐
│캘린더│ 목록 │우선순│ 설정 │
└──────┴──────┴──────┴──────┘
```

- 검색: 각 화면 상단 돋보기 아이콘
- 카테고리 관리: 설정 화면 내 별도 페이지

### 상세 보기 및 편집

| 항목 | 내용 |
|------|------|
| 상세 보기 | 모달 (PC: 팝업 / 모바일: 아래에서 올라오는 시트) |

## 2. 일정 vs Todo

> 동일한 폼, 동일한 DB 테이블. `is_todo` 토글로 구분.

| 항목 | 일정 | Todo |
|------|------|------|
| 시작 시각 | 필수 | 선택 (마감 기한) |
| 종료 시각 | 필수 (미입력 시 당일 23:59) | 없음 |
| 마감 정밀도 | 없음 | 연/월/일/시분 |
| 기한 초과 동작 | 없음 | 만료/유지 |
| 완료 체크 | 없음 | 있음 |
| 자동 삭제 | 종료 후 180일 (설정 변경 가능) | 완료 후 30일 (설정 변경 가능) |
| 알림 기준 | start_at (종일이면 하루 전만) | 마감 기한 (없으면 알림 불가) |
| 캘린더 표시 | 시간 블록 | 일간 뷰 하단 섹션 |
| 매트릭스 X축 | start_at 기준 긴급도 | 마감 기한 기준 긴급도 |

## 3. 기능별 명세

### 3.1 목록 화면

- 상단 탭: **Todo** / **일정** 전환
- Todo 탭 필터: **미완료** (기본) / **완료** / **전체**
- 정렬: **시간순** / **점수순**
- 시간순 구조 (Todo): 기한 있음 → `── 기한 없음 ──` 섹션
- 완료 처리: 체크 즉시 취소선, 미완료 탭에서 즉시 사라짐

### 3.2 등록 폼

| 필드 | 조건 | 상세 |
|------|------|------|
| 제목 | 필수 | 최대 100자 |
| 시작 날짜/시각 | 일정 필수, Todo 선택 | 일정: 날짜+시각 / Todo: 마감 기한 |
| 종료 날짜/시각 | 일정 전용 | 미입력 시 당일 23:59 |
| 종일 여부 | 일정 전용 | 켜면 시각 숨김, 날짜만 입력 |
| 마감 정밀도 | Todo 전용 | 없음/연/월/일/시분 |
| 기한 초과 동작 | Todo + 마감 있을 때 | 만료/유지 |
| 대카테고리 | 선택 | 드롭다운에서 바로 생성 가능 |
| 소카테고리 | 대카테고리 선택 후 | 드롭다운에서 바로 생성 가능 |
| 중요도 | 선택 | 1.0~10.0 슬라이더, 카테고리 선택 시 자동 채움 |
| 반복 설정 | 선택 | Phase 5 구현 예정 |
| 알림 설정 | 선택 | Phase 6 구현 예정 |
| 장소 | 선택 | 최대 100자 |
| 메모 | 선택 | 제한 없음 |

### 3.3 마감 기한 저장 방식 (Todo)

| precision | 입력 | 저장되는 값 |
|-----------|------|------------|
| none | — | start_at 비어있음 |
| year | 연도 (예: 2026) | 2026-12-31T23:59 |
| month | 연-월 (예: 2026-05) | 2026-05-31T23:59 |
| day | 날짜 | YYYY-MM-DDT23:59 |
| datetime | 날짜+시각 | 입력값 그대로 |

### 3.4 카테고리

- 대카테고리 > 소카테고리 2단계
- 각 카테고리별 독립 색상 + 기본 중요도 설정 가능
- 소카테고리 선택 시 소카테고리 기본 중요도 우선 적용
- 폼 드롭다운에서 바로 생성 가능 (이름/색상/중요도, order 자동 계산)
- PC: 사이드바 카테고리 탭에서 관리 / 모바일: 설정 내 페이지

### 3.5 우선순위 뷰

**아이젠하워 매트릭스**
- X축: 긴급도 (남은 시간 기준, 오른쪽일수록 긴급)
- Y축: 중요도
- 기한 없는 Todo → X축 맨 왼쪽(비긴급)

**점수 목록**
- 점수 = 중요도 × 긴급도점수
- 긴급도점수: 24h 이내=10, 1주=7, 1달=5, 기한없음=1
- 점수 내림차순 정렬

### 3.6 알림

- 타이밍: 10분/30분/1시간/하루 전 (복수 선택)
- 종일 일정: 시간 기반 선택지 비활성화, 하루 전만 가능
- 기한 없는 Todo: 알림 UI 비활성화
- 스누즈: 기본 10분 (설정 변경 가능)
- 반복 일정: 매 회차마다 자동 발송

### 3.7 반복 일정

- 주기: 매일/매주/매월/매년
- 요일 지정 가능 (예: 월·수·금)
- 종료 조건: 종료일 / 횟수 / 무기한 (생성 후 변경 가능)
- 수정/삭제 시 다이얼로그: 이 일정만 / 이후 전체 / 모두

### 3.8 오프라인

| 상황 | 동작 |
|------|------|
| 온라인 | PocketBase Realtime(WebSocket)으로 즉시 동기화 |
| 오프라인 | 로컬 캐시로 읽기·쓰기 모두 가능 |
| 복귀 | 오프라인 중 변경사항 자동 서버 반영 |
| 충돌 | 마지막 수정 시각 기준 |

### 3.9 캘린더

- 월간: 날짜 셀에 일정 제목 표시, 초과 시 "+N개"
- 주간: settings.calendar_slot_mins 단위 블록, 카테고리 색상
- 일간: 시간 블록 + 당일 Todo 섹션
- PC: 드래그 앤 드롭으로 일정 이동

### 3.10 설정 항목

| 항목 | 기본값 |
|------|--------|
| 테마 | system |
| 시간 표시 형식 | 24h |
| 기본 알림 시각 | [10분 전] |
| 스누즈 시간 | 10분 |
| 완료 Todo 자동 삭제 | 30일 |
| 지난 일정 자동 삭제 | 180일 |
| 시간 블록 단위 | 60분 |

### 3.11 PC 전용 (Electron)

- 위젯 형태 전환: 미니 캘린더 / 오늘 할 일 / 이번 주 타임라인
- 항상 위에 표시 (기본: false)
- 시스템 트레이 상주
- 전역 단축키: `Ctrl+Shift+F`
- 맥 로그인 시 자동 실행
- 창 크기: 380×600px, 최소 300×400px, frameless

### 3.12 모바일 전용 (Android)

- 홈화면 위젯 소: 다음 일정 + 미완료 Todo 수
- 홈화면 위젯 중: 오늘 일정 목록 (최대 5개)
- 홈화면 위젯 대: 이번 주 미리보기
- 스와이프: 오른쪽→완료, 왼쪽→삭제
